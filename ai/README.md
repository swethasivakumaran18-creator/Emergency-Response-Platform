**# AI Emergency Analyzer**



**## Purpose**



**The AI Emergency Analyzer analyzes emergency incidents and returns:**



**- Category**

**- Severity**

**- Summary**

**- Recommended response**



**## Input**



**The analyzer accepts:**



**- `type` - Type of incident**

**- `description` - Description of the incident**

**- `location` - Incident location**



**## Output**



**The analyzer returns:**



**- `category`**

**- `severity`**

**- `summary`**

**- `recommended\_response`**



**## Example Input**



**```json**

**{**

&#x20; **"type": "fire",**

&#x20; **"description": "A fire has started in a residential building and people are trapped inside.",**

&#x20; **"location": "Chennai"**

**}**
