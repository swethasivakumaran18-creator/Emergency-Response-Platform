# Emergency Response Platform — Hackathon Edition

A static HTML/CSS/JavaScript emergency coordination prototype.

## Features
- Multi-page navigation (no homepage section scrolling)
- One-tap SOS confirmation
- Browser Geolocation API
- Structured emergency report
- Smart priority/recommended response rules
- Command-center dashboard
- Leaflet + OpenStreetMap incident map
- Responder dispatch simulation
- LocalStorage persistence
- Responsive mobile UI

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## GitHub
```bash
git add .
git commit -m "Hackathon emergency platform upgrade"
git push origin main
```

## Vercel
Import the GitHub repository as a static project. No build command is required.

## Important
This is a hackathon prototype. It does not contact real emergency services or dispatch real responders. For a real emergency, use the appropriate official emergency service.
