# 🚨 Emergency Response Platform — Hackathon Edition

> **🌐 Live Demo:** https://emergency-response-platform-io.vercel.app/

A smart emergency coordination platform designed to reduce the time between incident reporting and initiating the appropriate response.

## Features

* 🚨 One-tap SOS confirmation
* 📍 Browser-based GPS location capture
* 📝 Structured emergency incident reporting
* 🧠 Smart emergency priority and response recommendations
* 🚑 Ambulance, 🚓 Police, and 🚒 Fire response workflows
* 🗺️ Command-center map using Leaflet + OpenStreetMap
* 📊 Emergency command-center dashboard
* ⚡ Responder dispatch and ETA simulation
* 💾 LocalStorage-based incident persistence
* 📱 Responsive mobile-friendly interface
